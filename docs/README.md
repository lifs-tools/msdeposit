# lifs-tools/msdeposit: Documentation

The lifs-tools/msdeposit documentation is split into the following pages:

- [Preparing a submission](submission.md)
  - Step by step from vendor files to a checked upload set: conversion, pseudonymisation, review of identifier hits and an independent post-hoc scan, with public MetaboLights studies as examples.
- [Usage](usage.md)
  - An overview of how the pipeline works, how to run it and a description of all of the different command-line flags.
- [Output](output.md)
  - An overview of the different results produced by the pipeline and how to interpret them.
